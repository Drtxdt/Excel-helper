主要运行依赖：Univer 1.2.0（Apache-2.0）、Vue / Vue Router / Vite / idb / Zod / markdown-it（MIT）、Lucide 图标（ISC）、React / React DOM（MIT）、RxJS（Apache-2.0）。完整版本与间接依赖见 pnpm-lock.yaml，各包许可原文在安装后的包目录中。
