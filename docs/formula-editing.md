# 原生编辑与输入诊断

练习与案件共用 Univer 1.2.0 的单元格编辑器和公式栏。`header: true` 与 `toolbar: false` 保留公式栏、关闭完整工具栏；教学栏只提供写入、撤销、重做和填充，不维护第二份公式草稿。

## 已复现的失败路径

- 引导的模态对话框先于原生编辑器初始化打开时，关闭后虽然原生编辑器取得焦点，Chromium 仍可能只发送 `keydown`，不发送 `beforeinput/input`，导致网格无法打字。将引导、帮助与重置弹窗的挂载约束为编辑器已渲染且首次计算完成，消除这条初始化路径。没有增加周期性抢焦点或固定延时。
- 任务地址只改变选区，没有通过布局服务归还键盘焦点。现在同时选择范围并调用引擎焦点接口。
- Univer 1.2.0 的部分选区操作没有触发可供教学栏使用的变化通知。适配层同时处理选区事件、设置选区和键盘移动命令，保持地址与当前值一致。
- 引擎的公式结果写回也会触发表格 mutation。将这些带 `fromFormula` 的通知计作新作答，会取消刚开始的检查；现在只以用户修改推进作答修订号。
- 地址栏的 Enter 需要停止冒泡，否则定位后的同一次按键还会触发原生编辑/下拉框。WebKit 触摸 `pointerdown` 被取消后不会再发出 `click`；防失焦处理只用于鼠标，触摸保留完整点击事件。
- 检查等待正在进行的填充和重算。地址栏编辑期间不被选区通知覆盖；切关清除旧操作的等待关系。

以上是本地实际复现的路径，不等于已经验证原私人 Site 的全部故障原因。

## 生命周期

适配层订阅开始编辑、编辑变化、提交前与结束事件，分别保存编辑目标和当前引用选区。写入、检查、课程路由离开、案件切阶段/结案/导出先调用 `endEditingAsync(true)`；检查随后等待计算，使用提交后的修订号。引擎返回后仍检查是否处于编辑状态，防止被输入诊断取消的提交继续进入判题。

组合输入期间显式写入/检查会提醒先确认选字。切关和释放会话清理订阅；迟到的旧实例事件不更新新关卡。单元格编辑直接使用原生 Enter、Escape、F2、候选与引用交互，不重新实现公式计算。

## 输入辅助的边界

函数候选与当前参数由引擎提供。课程知识卡补充用途、语法和注意事项，不插入解题答案，也不计作查看提示。

漏等号检测只用于明显的函数调用或算式。修正按钮绑定编辑修订号，“补上 =”只改变当前草稿；“按文字写入”只确认这一次输入。单引号明确指定的文本不转换。括号、引号和全角符号检查是教学诊断，不是第二套公式解析器。

检查结果包含稳定类别及定位动作；输入问题优先于数值差异，相同错误不在每组变式重复。计算/引擎异常与学习者错误分开。修改草稿即清除旧检查反馈，案件证据仍依据提交后的工作簿失效。

## 复核方式

```sh
pnpm check
pnpm exec playwright test --project=chromium --project=chromium-tablet --project=webkit-tablet
```

`native-editing.spec.ts` 从网格发送真实键盘输入；原有公式栏用例改为操作原生栏的 DOM，不调用应用写入接口。截图基线仍只在固定 Linux 容器生成与审阅。

数据验证列表在原生 UI 中使用搜索选择框：输入列表外文字是搜索，不是单元格编辑。回归验证无匹配项不能写入、原值保留，选择合法值后能保存恢复；不再期待已经移除的自建输入框抛出错误。

2026-10-24 的验证记录：

- `pnpm check`：301 个测试通过，包含 40 关和既有 Excel 黄金样例；类型检查、生产构建与体积预算通过。静态产物 18,510,899 字节，预算 20,330,755 字节。
- Windows 已安装的 Edge 156.0.4314.42：使用独立临时浏览器上下文、无头模式，10 个原生编辑用例通过。没有接触用户已有窗口或浏览器资料。
- Chromium / WebKit 平板仿真：候选触摸选择、补等号、写入、填充、切表、撤销重做与恢复通过。仿真不能代替真实 iPad / Android。
- 原生公式中间插入引用保留后文；光标在字符串内点选网格不会插入引用，此时遵循原生提交并选择单元格的行为。
- 1024 / 1366 / 1920 截图来自固定 Linux CI 运行 `40083785951` 的实际截图，经逐张审阅后更新基线；没有使用 Windows 截图。
- 完整浏览器回归与最终 CI 结果以 PR 的检查和报告为准。测试替换草稿时先用 Escape 关闭候选并取消编辑，不能把在未完成公式中的追加输入误当成替换。

独立安装的 Windows Chrome、真实中文输入法和原私人 Site 路径仍待验证。真实 Excel 黄金样例保留原验证版本，本次不宣称重新运行了桌面 Excel。

## 合并后的 Site 验收

在用户合并后更新原私人 Site，保留上一部署版本。登录后记录浏览器版本，分别检查首次进入并关闭引导、恢复旧草稿、关闭帮助、切关后直接输入；测试课程 02、07、10、条件汇总课和首案。遇到失败记录活动元素、编辑事件、遮挡元素与加载异常，不只记录“公式栏能用”。当前阶段不提前部署。
